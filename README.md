# Handalfabet Oefenen

Oefensite voor het Nederlandse handalfabet. Alles zit in `index.html`, ook de beelden en lettertypes.

## Op de computer
Dubbelklik op `index.html`. Dat werkt zonder internet.

## Op je telefoon, ook zonder bereik
1. Zet deze bestanden in een GitHub-repository en zet GitHub Pages aan via Settings > Pages (branch `main`, map `/root`).
2. Open de HTTPS-link eenmaal met internet.
3. iPhone: Safari > Deel > Zet op beginscherm. Android: Chrome > menu > Toevoegen aan startscherm.
4. Daarna opent de app ook zonder verbinding.

Let op: de handbeelden komen uit een video van Wapperkids. Een GitHub Pages-site is openbaar voor iedereen met de link. Vraag Wapperkids om toestemming voordat je de site zo online zet.

## Opslag
Je voortgang staat in localStorage op je toestel. Er is geen account of synchronisatie. Als je browsergegevens wist, verdwijnt de voortgang.
